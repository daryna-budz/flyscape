# ✈️ Flyscape Travel Booking App

A modern travel booking web application that allows users to explore destinations, browse travel categories, search for available flights and book tickets.

Built with a focus on responsive UI, dynamic routing, and interactive booking flows using modern frontend technologies.

---

## 🚀 Live Demo

Try the app here:  
👉 https://flyscape-app.netlify.app/

---

## 📖 About the Project

Flyscape is a responsive web application designed to simulate a real-world travel booking experience.

Users can:

- browse destinations by category
- explore destination cards
- view booking details for selected trips
- search for flights using an integrated API-powered booking flow

This project was built to strengthen skills in:

- Next.js App Router
- TypeScript
- Dynamic routing
- API integration
- Component-based architecture
- Responsive UI design

---

## ✨ Features

### 🌍 Destination Discovery
Browse destinations across multiple categories:

- Beach
- Mountain
- City
- Adventure
- Nature

---

### 🎫 Dynamic Ticket Pages

Each destination includes a dedicated booking page with:

- destination preview
- travel details
- booking form

---

### ✈️ Flight Search

Users can search flights by entering:

- departure airport
- travel date

Destination airport is automatically prefilled.

---

### 📱 Fully Responsive Design

Optimized for:

- mobile
- tablet
- desktop

## ⚙️ Installation

Run locally:

```bash
git clone https://github.com/daryna-budz/flyscape.git
cd flyscape
npm install
npm run dev
```

---

## 🔑 Environment Variables

Create a `.env.local` file:

```env
DUFFEL_API_KEY=your_api_key
```

## 📦 Deployment

The project is deployed using Netlify.

To build the project:

```bash
npm run build
```
